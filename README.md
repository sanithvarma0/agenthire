# AgentHire

A voice assistant that hires people for you, from an electrician to an engineer. You say who you need, it finds people, phones them in their own language, and brings back a shortlist for you to decide.

Built at Builders 2026 (OpenAI x Equal AI), 21–22 Nov 2026, under the Build Creative track.

**Status:** in development. This README is completed in the last phase of the build.
