# Demo video

**Link:** https://www.loom.com/share/6d99a4b2dab342ea872b739647ef26fd

A run of the product, up to 5 minutes, on the live deployment (https://3-213-208-226.sslip.io) in test mode: every call rings the builder's phone, and the builder answers as the provider or the candidate, with the phone on speaker so both sides are heard. Waits (the map search, writing, the web crawl, scoring) are paused out.

What a full run covers, and what to look for:

- **Gig worker:** the voice brief with the real-time avatar; real providers near the user on the night map; phone calls in Telugu with the live transcript and facts filling in; the comparison with each provider's own words; booking with a confirmation call and an SMS.
- **IT hire:** a role turned into a job description, five screening questions and a scoring guide, approved by HR; public profiles from the web crawl, with no contact details; a screening call; the shortlist, each answer scored 1 to 5 with the candidate's own words.

To run the same journeys yourself, see section 7 of [AGENTS.md](AGENTS.md).
