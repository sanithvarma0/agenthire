## 1. How we work

- **One task after another, in order.** A task is finished before the next one starts.
- **A phase is not done until its check has been run** and the result is written in the progress log.
- **Times are latest-finish targets, not a schedule.** If a phase finishes early, the next one starts straight away. There is no sleep block.
- **Test mode stays on until phase 8,** so nothing dials a stranger while we build.
- **Commit to git at the end of every phase,** and after any task that leaves things working.
- **No new features after 9:00 AM Sunday.** From then on, only testing, fixes and the submission.
- **No hardcoding** (see `LLD.md`, section 1).
- **Documents stay true.** When a test or a task changes a decision, the affected document is updated in the same task.
